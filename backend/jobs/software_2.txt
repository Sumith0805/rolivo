Backend Engineer (Java)

About the role

Responsibilities
- Build and maintain microservices in Java and Spring Boot

- Model data in relational databases and write efficient queries
- Add logging, metrics and automated tests to every service
- Review code and mentor junior engineers

Requirements
- 1 to 3 years of backend software engineering experience
- Solid Java, object-oriented design and data structures
- Experience with microservices and message queues such as Kafka
- Familiarity with Docker
